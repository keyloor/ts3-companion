TOY STORY 3 COMPANION 1.0.1  (unofficial / no oficial)
=======================================================

EN
--
100% companion for Disney/Pixar Toy Story 3 Complete Edition (PC/Steam).

1. Extract the folder anywhere (it does not go in the game folder).
2. Run TS3Companion.exe. It opens in its own window (it uses Edge or Chrome).
3. Your save is found automatically. If not, press "Find save..." and pick the
   "Saved Game" file; the location is remembered.
4. Press "Sync now". With auto-sync on (Settings), it also syncs every time
   you save in-game or unlock a Steam achievement.
5. Close the window to quit.

- It only READS your save and Steam's achievement cache. It never modifies
  the save, the game or Steam.
- Progress is stored in %APPDATA%\TS3Companion\progress.json
- Windows SmartScreen may warn because the exe is not signed:
  "More info" > "Run anyway". The source code is on GitHub.
- Not affiliated with Disney, Pixar or Avalanche Software.

ES
--
Compañero al 100 % para Toy Story 3 Complete Edition (PC/Steam).

1. Descomprime la carpeta donde quieras (no va en la carpeta del juego).
2. Abre TS3Companion.exe. Se abre en su propia ventana (usa Edge o Chrome).
3. Tu partida se encuentra sola. Si no, pulsa "Buscar partida..." y elige el
   archivo "Saved Game"; la ruta se recuerda.
4. Pulsa "Sincronizar ahora". Con la sincronización automática (Opciones),
   también se sincroniza al guardar en el juego o al desbloquear un logro.
5. Cierra la ventana para salir.

- Solo LEE tu partida y la caché de logros de Steam. Nunca modifica la
  partida, el juego ni Steam.
- El progreso se guarda en %APPDATA%\TS3Companion\progress.json
- Windows SmartScreen puede avisar porque el exe no está firmado:
  "Más información" > "Ejecutar de todas formas". El código está en GitHub.
- Sin relación con Disney, Pixar ni Avalanche Software.
